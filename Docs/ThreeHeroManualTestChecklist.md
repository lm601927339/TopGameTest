# 三英雄手工验收清单

本清单记录目前仍需在 Unity Play Mode 中逐项确认的行为。预制体、角色动画和正式特效不在本轮范围内。

## 运行前

- 在 `GameDesignConfig` 保持 `showHeroSelectionPanel = true`。
- 确认场景存在 `Canvas`、`PlayerHP`、`GameManager` 和可生成敌人的基础地图。
- 进入 Play Mode 后打开 Console；每项测试前清除上一次生成的敌人和日志。

## 英雄选择与扩展

- 点击三个内置英雄卡片后，场景应重载，且卡片高亮、基础属性、初始技能和按键均切换到所选英雄。
- 退出并再次进入战斗，最后选择应通过 `PlayerPrefs` 恢复。
- 在 `heroDefinitions` 添加一个有效自定义英雄：应出现在三位内置英雄之后，卡片使用其 `roleDisplayName` 和 `specialtySummary`。
- 将自定义英雄的技能 ID 或预制体路径故意填错：启动校验应输出明确 Warning，旧玩家回退路径不得崩溃。

## 暗影潜行者

- `Fire1` 释放隐身后，HUD 显示“隐身”并从约 4 秒倒计时至消失；普通敌人不得再选中该角色作为目标。
- 给敌人挂载 `TargetDetectionProfile` 并启用 `canDetectInvisible` 后，该侦测敌人应能重新锁定隐身英雄；普通敌人仍不能锁定。
- 让普通敌人已追击英雄后释放隐身：敌人应先前往英雄最后可见位置，在约 2.5 秒内原地搜索，再恢复随机巡逻；不得继续追踪隐身英雄的实时位置。
- 侦测敌人面对同一隐身英雄时应保持追击，不应进入搜索或巡逻；可选挂载 `EnemyAwarenessProfile` 调整普通敌人的搜索时长和抵达距离。
- `Fire2` 回旋镖命中与返回路径正常；`Jump` 翻滚后移动控制不应卡死。
- 受到中毒时，确认状态图标与实际中毒结束时间一致。

## 毒雾炼金师

- `Fire1` 中毒弹命中敌人后，目标同时出现中毒、减速和 DOT；三者应同步结束。
- 让毒雾炼金师受到 5 秒中毒：实际持续时间应约为 2 秒（60% 中毒时长减免），且 DOT/减速不得在图标消失后继续。
- `Fire2` 手雷与 `Fire3` 再生仍应遵循原有冷却、弹药和生命结算。

## 风暴术士

- `Fire1` 变羊期间，目标不能移动或施法；结束后控制恢复，临时羊模型和闪光清理。
- `Fire2` 闪电只攻击范围内最近敌人，命中伤害和眩晕都生效。
- `Fire3` 冰冻期间目标不能操作；风暴术士自己受到冰冻/眩晕时，分别验证 35%/20% 时长减免。
- `Fire4` 加速开始和结束均正确恢复属性，连续施放不产生永久叠加。

## HUD 与回归

- 玩家受到隐身、中毒、冰冻、眩晕、变羊、无敌时，`PlayerHP` 下方图标和倒计时必须准确刷新、到期清理。
- 多个状态同时存在时，图标不得互相覆盖；状态来源刷新时，倒计时应重新开始。
- 场景重载、角色死亡和返回主菜单后，不得残留英雄选择面板、羊模型或状态图标对象。
